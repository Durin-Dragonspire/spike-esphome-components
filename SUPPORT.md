# Support

Confirm the ESPHome error, board framework, component release tag, and protocol
version before requesting support. Never include API keys, Wi-Fi credentials,
fingerprint data, module passwords, or complete Home Assistant diagnostics.

The public component repository is not a distribution of SPIKE Home Alarm.

This repository will be archived read-only when the component moves into the
final public SPIKE Home Alarm distribution. Existing immutable tags will remain
available. After that migration, report new component issues through the
successor location named in the archive notice; this repository will no longer
accept changes or support requests.
