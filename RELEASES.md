## fingerprint-grow-v2.0.0

- Component version: `2.0.0`
- Component runtime-control ABI: `2`
- Firmware/Home Assistant status handshake: `2`
- Status: published
- Tag commit: `1459fabc63330ebced1afe00240868cfbf7ac0f2`

This release contains only the `fingerprint_grow` ESPHome component, its MIT
license, and a checksum manifest generated by SPIKE's allowlist exporter.

distinct timeout versus authentication failures. Generated SPIKE YAML still
supplies the correlated version-2 firmware-status envelope. GitHub enhanced
mode and local-copy enhanced mode compile this same artifact.

## Future migration

The standalone component repository will be archived read-only after the final
public SPIKE Home Alarm repository becomes the canonical component host. It
will not be deleted: immutable tags remain available for existing generated
YAML. The archive notice and this release index will identify the successor
location before newly generated YAML changes to it.
